# できたログ

「やったこと」を数秒で記録して、積み上げた成果を見るためのスマホ向けWebアプリです。

- **記録**：やったことを入力し、カテゴリと時間（任意）を選んで「記録する」を押します。よくやることはワンタップで入力できます。過去の日付でも記録できます。
- **成果**：連続日数、今週の件数、合計件数を表示します。ほかに、直近20週の積み上げカレンダー、カテゴリ別の先週比、週ごとの推移も見られます。
- **履歴**：日付ごとの一覧と検索。
- **設定**：カテゴリの編集、バックアップの書き出しと読み込み。

## 公開方法（最初に1回だけ）

1. GitHubでこのリポジトリを開きます。
2. **Settings → Pages** を開きます。
3. Source を **Deploy from a branch** にします。
4. 公開したいブランチと `/ (root)` を選んで **Save** を押します。
5. 数分後に表示されるURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）をスマホで開きます。
6. **ホーム画面に追加**します。
   - iPhone：Safariで共有ボタン →「ホーム画面に追加」
   - Android：Chromeのメニュー →「ホーム画面に追加」

ファイルは `index.html` などの静的ファイルだけなので、ビルド作業もサーバーもいりません。

## データについて（重要）

- 記録はスマホのブラウザの中（localStorage）だけに保存されます。サーバーには送られません。
- 次のような場合、**データが消える可能性があります**。月1回程度、「設定 → 書き出す」でファイルに保存してください（iCloud Drive / Googleドライブなど）。
  - ブラウザのデータ削除や機種変更をしたとき
  - iPhoneでホーム画面に追加せず、Safariで長期間開かなかったとき
- ホーム画面から開いたアプリとSafariで開いたページは、**別々の保存場所**になります（iPhone）。必ずホーム画面のアイコンから使ってください。
- 書き出したファイルを別の端末で「読み込む」と移行できます（同じ記録は重複しません）。
