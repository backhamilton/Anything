# できたログ

「やったこと」と「気分」を数秒で記録し、過去の自分と比べて積み上げを確かめるための、スマホ向けWebアプリです。

## 判断基準（機能を足す・変える前に必ず照らし合わせる）

1. **目的は生活を良くすること。** 記録や機能はそのための手段です。
2. **報酬は副産物。** ポイント、ランダムな演出、連続日数は使いません。
3. **比べる相手は過去の自分だけ。** 他人との比較やランキングは作りません。
4. **結果より過程を言葉にする。** 伸びしろは情報として伝え、大げさな褒め言葉は使いません。
5. **休むことも積み上げ。** 「増えた＝良い」とは決めつけません。
6. **大きな問題がない限り、機能は増やさない。** まず使ってから判断します。

## できること

| 画面 | 内容 |
|---|---|
| 記録 | 記録する日を選び、やったことを入力します。カテゴリ・時間（任意）・量（任意。例：20回、30ページ）も付けられます。今日の気分は1日1回、ひとことメモも付けられ、やったことがない日も記録できます。「よくやること」をタップすると、前回の時間と量も入ります。 |
| 成果 | これまでの積み上げ（記録した日数・回数・時間）と、次の節目までの日数を表示します。4週間のふり返り、できるようになったこと（量の伸び）、カテゴリ別の比較（直近4週間とその前の4週間）、週ごとの推移、カレンダー、気分の推移も見られます。 |
| 履歴 | 日ごとに、記録・気分・メモを一覧表示します。検索もできます。 |
| 設定 | カテゴリの編集、バックアップの書き出しと読み込み。 |

## 評価のしくみ（AIではありません）

成果画面の文章は、記録データの集計と、下のルールで決まった定型文だけで作っています。端末の外にデータは送りません。

- **ふり返り（直近4週間とその前の4週間を比較）**
  - 記録した日数を比べます。差がその前の4週間の15%以下（最低1日）なら、「同じくらいのペース」とします。小さな差を「増えた・減った」と言わないためです。
  - 休息カテゴリの記録があれば、「休むと決めて休めた日」として伝えます。
  - 同じ活動・同じ単位の量で、4週間より前の最高をこの4週間の最高が上回れば、「できる量が増えた」と伝えます。
  - 伸びしろとして、次のどちらか1つを伝えます。
    - 前の4週間に2日以上記録があったのに、この4週間は0日のカテゴリ（休息は除く）
    - 直近8週間で、平日と週末の一方の記録が、もう一方の半分未満
- **記録したときの一言**：表示する一言は、上から順に最初に当てはまる1つです。
  1. 自己ベスト
  2. 休息
  3. 最初の記録
  4. はじめての活動
  5. 3日以上空いた後の再開
  6. どれにも当てはまらないときは、今週何日目か
- **節目**：記録した日数（10・30・50・100・150・200・300・365日…）と、カテゴリ別の累計時間（10・30・50・100時間…）で数えます。同じ節目は1回だけ表示します。
- **気分とやったことの関係**：気分の記録が30日分たまってから表示します。各グループ5日以上、差が0.3以上のものだけを出します。相関であって、原因とは限りません。
- **低い気分が続いたときの一言**：直近14日のうち、気分が「低め」以下の日が10日以上あると表示します。表示は週1回までです。

## 公開方法（最初に1回だけ）

1. GitHubでこのリポジトリを開きます。
2. **Settings → Pages** を開きます。
3. Source を **Deploy from a branch** にします。
4. 公開したいブランチと `/ (root)` を選んで **Save** を押します。
5. 数分後に表示されるURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を、スマホのChromeで開きます。
6. メニューから **ホーム画面に追加** します。

## データについて（重要）

- 記録はスマホのブラウザの中（localStorage）だけに保存され、外部には送られません。
- ブラウザのデータを消したり機種変更したりすると、データが消えます。月1回程度、**設定 → 書き出す** でファイルを保存してください（Googleドライブなど）。
- 書き出したファイルを別の端末で **読み込む** と、データを移せます（重複は除外されます）。
- 気分やメモをもっと深く分析したいときは、書き出したファイルを自分の判断でAIに渡す方法もあります。その場合、メモの内容は外部のサービスに送られます。
